# 實機與投影測試清單

這份清單要由真人用真的手機、真的投影執行。**所有「結果」欄目前都是「待執行」。** 沒有人跑過真機，AI Agent 做的探索式 QA 只用了桌面 Chromium 模擬，見 [qa/README.md](qa/README.md)，那些結果不能代替這份清單。

填表方式：結果欄寫「通過」、「不通過」或「有疑問」，備註寫看到的現象（截圖放在 PR 或 issue 裡）。不通過的項目請開 issue，附機型、系統版本與重現步驟。

## 準備

- 辦一場試玩、要用筆電在區網跑服務時，照 [playtest.md](playtest.md)（`npm run start:lan`、防火牆、手機連不上怎麼辦）。
- 一台電腦跑服務（`npm run build && npm start`，或照 [deployment.md](deployment.md)），`PUBLIC_BASE_URL` 設成手機連得到的網址（區網 IP 或正式網址）。
- 手機要連得到：同一個 Wi-Fi，或用 HTTPS 網址。
- 測試用手機至少：iPhone（iOS Safari）一台、Android 手機（Chrome）一台。
- 填寫人、日期、機型與系統版本寫在最下面的「測試環境」表。

## C. 6 到 10 人完整一場

找 6 到 10 位真人（愈接近實際使用愈好），每人用自己的手機。由主持人從 Lobby 開始，玩到結束，再按「再玩一場」玩第二場。

| 編號 | 項目                                              | 結果   | 備註 |
| ---- | ------------------------------------------------- | ------ | ---- |
| C1   | 所有人都能在 2 分鐘內加入（有人卡住請記下卡在哪） | 待執行 |      |
| C2   | 沒有人看過說明，開始前主持人說明規則花了多久      | 待執行 |      |
| C3   | 有沒有人搞不清楚「查看題目」怎麼用                | 待執行 |      |

| C5   | 有沒有人想輸入房間代碼卻找不到地方（QA-03）       | 待執行 |      |
| C6   | 揭曉時大家能不能看懂結果                          | 待執行 |      |
| C7   | 遊戲中有沒有人斷線或被踢出，怎麼處理的            | 待執行 |      |
