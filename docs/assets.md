# 素材來源與授權

這個專案裡所有圖片都是在這個 repo 內自己寫的，沒有用任何第三方素材、角色、迷因或參考圖。授權跟專案本身相同。

| 檔案                              | 用途                                        | 做法                                                                                                     |
| --------------------------------- | ------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `src/client/assets/avatars/*.svg` | 15 種預設頭像（`01-` 到 `15-`，依檔名排序） | 用基本幾何形狀（圓、方、三角、星、心…）手寫 SVG 路徑，再各自加上不同的表情。沒有描圖，也沒有參考現成角色 |
| `src/client/assets/cover.svg`     | 首頁、Lobby、加入畫面的封面                 | 用上面五個頭像的圖形，加上手畫的手臂、虛線和問號，排成互相指向對方的樣子                                 |
| `public/favicon.svg`              | 瀏覽器分頁圖示                              | 手寫 SVG，一個懷疑表情的圓形角色                                                                         |
| `public/og.png`                   | 分享連結時的預覽圖（1200×630）              | 由 `cover.svg` 加標題文字合成，用 `node scripts/make-og.mjs`（Playwright 截圖）產生                      |

## 規則

- 新增圖片要在這裡補一列，說明誰做的、怎麼做的。
- 不放使用者提供或網路上抓來的圖。要用第三方素材時，先確認可商用，並在這裡寫下來源與授權。
- 頭像要靠輪廓與圖案分辨，不能只靠顏色。每個頭像的外形都不同（圓、方、三角、菱形、星、心、貓耳、兔耳、機器人、雲、六角形、水滴、花、條紋球、幽靈），灰階截圖也分得出來。
- 圖裡沒有文字。標題「誰跟我不一樣？」由頁面的 `<h1>` 顯示，只有 `og.png` 把標題畫進圖裡。
- 改了 `cover.svg` 之後要重跑 `node scripts/make-og.mjs`。
