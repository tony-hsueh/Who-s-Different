# 試玩指南

這份是辦一場試玩用的，分兩部分：[主持人（Tony）](#一主持人) 和 [同事](#二同事)。遊戲在同一間會議室玩，手機連筆電上跑的服務，筆電接投影。

## 一、主持人

### 事前準備

- 筆電裝好 Node.js 20.19 以上、npm 10 以上、Git。
- 筆電和所有人的手機連**同一個 Wi-Fi**。
- 筆電接好投影，先確認畫面能投出去。
- 玩之前先用自己的手機連一次，確認連得上（見下面「手機連不上」）。

### 啟動服務

在專案資料夾執行：

```bash
npm ci && npm run build && npm run start:lan
```

`start:lan` 會自己做這幾件事：

- 找出筆電的區網 IP（優先 192.168.x.x，其次 10.x、172.16 到 31），把所有候選都印出來，用第一個。
- 把 `PUBLIC_BASE_URL` 設成 `http://<IP>:3000`，大螢幕的 QR Code 就會指到手機連得到的網址。你自己先設了 `PUBLIC_BASE_URL` 就用你設的。
- 沒設 `ADMIN_TOKEN` 就隨機產生一個，只印一次（查 Event Log 才會用到，不查可以不管）。
- 啟動 Server。要換連接埠就先設 `PORT`，例如 PowerShell 用 `$env:PORT=3001; npm run start:lan`。

啟動後畫面會印出「在筆電上用瀏覽器打開」的網址，照著打開。

### Windows 防火牆

第一次跑要放行連接埠，手機才連得進來。用**系統管理員身分**開 PowerShell，執行：

```powershell
netsh advfirewall firewall add rule name="Whos-Different" dir=in action=allow protocol=TCP localport=3000
```

玩完用同樣的方式移除：

```powershell
netsh advfirewall firewall delete rule name="Whos-Different"
```

如果 Windows 跳出「允許 node.exe 通過防火牆」的視窗，選「私人網路」並允許，也可以。

### 投影什麼

- 筆電用瀏覽器打開 `start:lan` 印出來的網址，按「建立房間」，把這個瀏覽器視窗投出去。大螢幕上有 QR Code、房間代碼和玩家名單。
- **不要**把主持人頁面以外的東西投出去。玩家的詞語只在各自手機上，大螢幕看不到。

### 主持人要注意

- **整場一直用同一個瀏覽器、同一個網址。** 主持權限存在這個瀏覽器裡。換瀏覽器、換網址（例如從 `localhost` 換成 IP）或清除網站資料，就會看到「這個瀏覽器沒有這個房間的主持權限」，而且沒辦法接手。重新整理沒問題。
- 不要關掉跑 `start:lan` 的視窗，也不要讓筆電睡眠。服務一停，所有房間就消失。
- 筆電換 Wi-Fi 或 IP 變了，手機的連線會斷。要換就重新啟動、重新建房間。

### 手機連不上

按順序檢查：

1. 手機和筆電是不是同一個 Wi-Fi。有些公司 Wi-Fi 有分訪客網路和內部網路，要連到同一個。
2. 防火牆規則有沒有加（上面那段）。
3. 手機瀏覽器直接打開 `http://<IP>:3000/healthz`，看到 `{"ok":true}` 代表網路是通的。
4. 公司 Wi-Fi 常開「用戶端隔離」，手機之間、手機和筆電不能互連，上面三項都對也連不上。這時改用隧道，讓手機走網際網路連進來，做法見 [deployment.md 的「用隧道」](deployment.md#用隧道不能直連區網時)。也可以用筆電開手機熱點，讓大家連它。

### 玩完

- 在跑 `start:lan` 的視窗按 Ctrl+C 停掉服務。
- 移除防火牆規則。
- 如果要看這場的事件紀錄，用印出來的 `ADMIN_TOKEN`，做法見 [event-log.md](event-log.md)。

## 二、同事

### 怎麼加入

1. 用手機相機或瀏覽器掃大螢幕上的 QR Code。
2. 輸入暱稱（最多 12 個字），按「加入」。
3. 看到「等待主持人開始」就好了。**不要關掉這個頁面。** 手機鎖屏或切到別的 App 後再回來，會自動回到原本的座位，不用重新加入。

掃不了 QR Code 的話，手機瀏覽器打開大螢幕上的連結也可以。

### 怎麼看詞語

- 遊戲開始後，手機上按「查看題目」就會顯示你的詞語，再按一次「隱藏題目」收起來。
- 詞語預設是藏起來的。**看完請馬上收起來**，旁邊的人看得到你的手機。
- 切到別的 App、鎖屏、手機進背景時，詞語會自動隱藏。
- 手機不會告訴你自己是多數還是少數，這要自己從大家的描述推測。

### 遊戲規則（5 行）

1. 大家拿到的詞語幾乎一樣，只有一個人或少數幾個人拿到不一樣的詞。沒有人知道自己是哪一邊。
2. 輪流用一句話描述自己的詞語，**不能直接說出來**。
3. 每個人都說完之後，大家用口頭討論、投票，選出最可疑的人（網頁不做投票）。
4. 主持人在大螢幕上淘汰被投出去的人，大螢幕會揭曉他是平民（多數）還是臥底（少數）。被淘汰的人仍然可以看自己的詞語，繼續觀戰。
5. 臥底全部被淘汰，平民獲勝；臥底人數追上平民人數，臥底獲勝。

少數人數：4 到 6 人 1 位、7 到 10 人 2 位、11 到 15 人 3 位。

### 玩的時候要知道的限制

- 遊戲開始後就不能再加入，晚到的人要等下一場。
- 人數要 4 到 15 人。
- 輪流順序、計時、投票都靠現場的人自己喬，網頁不管。
- 離線的玩家名單上還是會留著，不會被移除。
- 如果在遊戲中弄丟了網頁（例如清除了網站資料），回不到原本的座位。
- 服務重新啟動後，進行中的遊戲會全部消失，要重新建房間。
- 手機換網路（Wi-Fi 切行動網路）時，畫面最久要約 20 秒才會發現斷線並重連。

其他已知的限制見 [known-limitations.md](known-limitations.md)。試玩後的意見請記下來，真機測試的項目在 [manual-test-checklist.md](manual-test-checklist.md)。
